# Nightshift

Приложение для macOS и Linux, где человек ставит задачи агентам и уходит, а они сами делают, проверяют и мержат работу в main. Человека зовут только тогда, когда без него нельзя.

## Язык

**Среда**:
Агентская программа на этом компьютере (Claude Code, Codex, Gemini, opencode, Cursor, Qwen или своя команда). Внутри среды работает только она сама: свои модели, задачи, лимиты и настройки.
_Избегать_: движок, агент (как программа), адаптер, CLI

**Задача**:
То, что поручил человек: текст, проект и среда. Одна задача даёт одну ветку и один итоговый коммит.
_Избегать_: таск, тикет, джоб

**Роль**:
Что делает агент в задаче: Планировщик, Критик плана, Автор тестов, Исполнитель, Ревьюер, Проверяющий, Интегратор; в рое и на фабрике ещё Координатор и Надзиратель.
_Избегать_: агент (как должность), исполнитель (для любой роли)

**Запуск**:
Один вызов среды с одной ролью и своей сессией. Каждая роль задачи - отдельный запуск.
_Избегать_: прогон, сессия (это только память запуска)

**worktree**:
Отдельная копия репозитория (git worktree), где работает только эта задача. Папку человека задача не трогает, пока её не смержат.
_Избегать_: копия задачи, рабочая копия, песочница

**Проверки**:
Все проверки проекта: тесты, сборка, линтер, типы. Пока хоть одна красная, задача дальше не идёт.
_Избегать_: Ворота, CI, гейты

**Merge** / **Смержить**:
Готовая задача попадает в main одним коммитом.
_Избегать_: Влив, Влить, слияние

**Merge-очередь**:
Порядок, в котором готовые задачи попадают в main по одной: каждая перед этим заново проверяется на свежей main.
_Избегать_: Очередь слияния, пайплайн слияния

**Нужен ты**:
Три повода позвать человека: вопрос агента, «Не вышло», разрешение на push / PR. Янтарный цвет в интерфейсе принадлежит только им.
_Избегать_: алерт, уведомление (это способ, а не повод), эскалация

**push / PR**:
Любое действие, видимое за пределами этого компьютера: push, PR, а у запушенной задачи ещё и откат.
_Избегать_: Наружу, деплой, публикация

**После готовности**:
Что происходит с готовой задачей: смержить локально, смержить и запушить, либо запушить ветку и открыть PR.
_Избегать_: Финиш, релиз, завершение

**Конфиг** (экспорт/импорт):
Выгрузка скиллов, правил, хуков, MCP, субагентов и настроек одной среды для переноса на другую машину или другому человеку. Секреты в конфиг не входят.
_Избегать_: Набор, пакет, профиль, бэкап

**Снимок**:
Копия того, что конфиг заменил при установке, чтобы его можно было откатить.
_Избегать_: бэкап, чекпоинт

**Рой**:
Несколько агентов одной среды на одной задаче: Соревнование, Бригада или Совет.
_Избегать_: команда агентов, мультиагент

**Фабрика**:
Экран всего производства одной среды: кто работает, кто завис, что стоит в Merge-очереди.
_Избегать_: дашборд, пульт

**Поручение**:
Одна фраза на фабрике, которую Координатор разбивает на несколько связанных задач с общим прогрессом.
_Избегать_: эпик, проект (проект - это папка с репозиторием)

**Панель**:
Скруглённое «окно» внутри вкладки, как в тайлинговом WM: сессия агента (лента) или терминал. Вкладка делится на панели сплитами, до 6.
_Избегать_: пейн, фрейм, окно (окно - это окно приложения)

**Бар**:
Строка состояния внизу окна из модулей: среда, модель, ветка, лимиты, часы, палитра.
_Избегать_: статус-бар, футер, полоса сред

**Палитра**:
Список всех команд по ⌘K с нечётким поиском.
_Избегать_: меню команд, лаунчер
