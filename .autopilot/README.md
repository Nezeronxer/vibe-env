# Как читать эту папку

- `dashboard.html` — открывается сам в начале сборки; можно и двойным кликом.
  Этапы, прогресс, время, что осталось. Обновляется сам, пока сборка идёт.
- `vibe-env/<дата>-brief.md` — твоя изначальная задача, слово в слово. Не редактируется.
- `vibe-env/manifest.md` — список требований и что с каждым стало.
- `vibe-env/spec.md` — спецификация.
- `vibe-env/tickets/` — таски, на которые разбита сборка (если сборка мелкая, их нет).

Если сборка прервалась — скажи агенту «продолжи автопилот», он поднимет состояние отсюда.
