# Референсы интерфейса - разбор 2026-10-21 (неполный)

Mobbin: требует платный план - экранов нет. Chrome-расширение не подключено - Pinterest/Dribbble/Behance не открылись. Ниже - только реально прочитанное.

## Источники
- Superset (github.com/superset-sh/superset, открыто): воркспейс = worktree + терминалы; статус агента в сайдбаре, звук при завершении, бейдж «нужен человек»; diff с комментариями агенту.
- Gas Town `gt feed` / `gt dashboard` (открыто): три панели - дерево агентов по ролям · конвои · лента событий; вид «Проблемы» (Stalled / Zombie / Working / Idle) с действиями «подтолкнуть», «передать».
- Cursor Agents (cursor.com/features, открыто): сайдбар задач по статусам со счётчиками, время и diff-статистика у задачи, режим Plan, сводка «Worked for 14m».
- OrchVis (arxiv.org/html/2510.24937v1, открыто): иерархия целей со сворачиванием, конфликт помечен на узле, пауза только затронутой ветки.
- Agent Beecolony / Swarm-IDE (из выдачи): граф топологии роя + диалог с любым агентом в дереве.

## Раскладки-кандидаты
A «Почта для агентов» (3 колонки: нужен ты/задачи · задача с вкладками План/Чат/Diff/Тесты · состав ролей + Рой + Качество).
B «Командный пункт» по `gt feed` (фабрика-дерево · конвои + чат · лента).
C «Ночная смена» (дорожки ролей на временной шкале, очередь слияния трубой в main, внизу лента+чат и «нужен ты»).

## Приёмы для роя и фабрики
Дерево ролей с агрегатами «×3»; вид «Проблемы»; одна форма и цвет значка на роль везде; сворачиваемая иерархия; очередь слияния - отдельная «труба» перед main; звук + бейдж при «нужен ты».

## Чего избегать
Частицы и декоративные графы; фиолетовые градиенты, свечение, стекло; аватарки-роботы вместо ролей; тысячи мерцающих точек вместо агрегатов; «нужен ты» без причины и действия.
