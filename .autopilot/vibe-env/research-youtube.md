# Приёмы из YouTube: параллельные агенты, токены, фабрики - разбор 2026-10-23 (с речью)

Что сделано: поиск на YouTube через OpenCLI (Chrome), 11 роликов. Речь расшифрована у всех 11 (локально, whisper-cli, без установок). Экран разобран через frameproof 0.7.1 (индекс кадров + OCR) у 7 роликов. Главы и описания - со страниц роликов.

## Метод

- Звук: `yt-dlp` (аудио без видео) → `ffmpeg` 16 кГц mono wav. У Pocock и Cole Medin первая загрузка не содержала звуковой дорожки, аудио докачано отдельно.
- Расшифровка: `whisper-cli -m ggml-large-v3-turbo-q5_0.bin -l auto -otxt -osrt`. Язык определяется сам (Sean Kochel - en, p=0.9999).
- Тайм-коды речи: `[MM:SS]` из srt. Для 7 индексированных роликов frameproof пересобран с `--subs <srt> --ocr` (индексы `<имя>_sp`): речь находится как `[MM:SS / seg#N]`, экран как `[MM:SS / fNNNN]`. Проверено: `frameproof search "unique port"` возвращает речь с меткой.
- Для 4 роликов без видео (Kevin, Nate, Jaymin, Артём) использован только srt, без кадров.
- Установок не делал. Блокировку `mlx-whisper` хуком `pkg-guard.py` больше не нужно обходить: whisper-cli из Homebrew и модель VoxFlow уже есть.
