# Фабрика агентов - модель Gas Town (локальный разбор 2026-10-21)

Источники: `/opt/homebrew/Cellar/gastown/1.1.0/README.md`, `~/gt/CLAUDE.md`, `gt <cmd> --help`. Тексты промптов ролей не читались (зашиты в бинарь).

## Роли
- **Overseer** - человек: ставит задачи, получает эскалации.
- **Mayor** - координатор: разбивает слова человека на задачи (beads) и группы (convoy), раздаёт.
- **Polecat** - рабочий: одна задача на сессию, свой worktree, выход - ветка + `gt done` с исходом COMPLETED / ESCALATED / DEFERRED. Статусы Working / Stalled / Zombie / Idle.
- **Witness** - надзиратель на проект: ловит зависших (15 мин без прогресса - stalled, 30 мин с задачей - нарушение), будит, чистит.
- **Refinery** - очередь слияния: ребейз, проверки, merge в main по одному; конфликт → новый рабочий.
- **Deacon / Dogs / Boot / Daemon** - сторожа сторожей и уборка (на одном ноутбуке не нужно).
- Общение: mail (сохраняется), nudge (толчок без сохранения), hook (задача, прикреплённая к агенту, переживает рестарт).

## Поток
человек → Mayor → convoy + задачи → sling → Polecat в worktree → (Witness следит) → `gt done` → Refinery: rebase, проверки, merge → convoy «приземлился» → уведомление.

## Как человек видит
`gt feed` - TUI из трёх панелей: дерево агентов · конвои · поток событий; `--problems` группирует агентов по состояниям (нарушение / stalled / zombie / working / idle) с действиями «зайти в сессию», «толкнуть», «передать». `gt dashboard` - веб по конвоям с индикатором свежести. `gt estop` - аварийная заморозка с сохранением контекста.

## Переносим в Nightshift
1. Задача хранит своё состояние (hook) - перезапуск ничего не теряет (уже так в движке).
2. Один агент - одна задача - один worktree (уже так).
3. Исход агента из трёх: сделал / нужен человек / отложил - «не могу» не выглядит падением.
4. Последовательная очередь слияния с ребейзом и проверками (уже так); конфликт - свежий агент.
5. Детектор зависших по таймеру.
6. Экран «проблемы»: кому я нужен, с действиями.
7. Конвой - группа задач с общим прогрессом (поручение → подзадачи).
8. Аварийная заморозка + лимит параллельности.

## Не переносим
Mayor отдельным агентом (интерфейс и есть Мэр; разбиение - один вызов «разбей на задачи»), Deacon/Dogs/Boot, Dolt/beads/mail, федерацию, Crew, email/sms-эскалации, формулы.
