# Визуальные референсы (G06)

18 шотов с Dribbble (`https://dribbble.com/shots/<id>` - id в имени файла), отобраны вручную, лендинги и декор отброшены. Pinterest не смотрели.

Берём:
1. Очередь «нужен ты» отдельной колонкой с готовыми действиями (01, 03).
2. Один словарь статусов на весь продукт (12: Completed, Running, Failed, Skipped, Queued, Timed-out, Awaiting input, Paused).
3. Фабрика - поток нод с карточками ролей (06, 11).
4. Настройки роли - инспектор справа, без модалок (10, 07).
5. Чат как главная/консольная панель рядом с роем (04, 14, 18); сайдбар сессий + поле ввода (14); строка ввода с выбором модели (15).

Избегаем: hero и маркетинг внутри приложения (05, 15); декоративные сферы и кольца вместо цифр (08, 02); неон и свечение на тёмном; цвет статуса без подписи.

Сбор: `opencli dribbble shot` сломан (selector drift) - обход через `opencli browser open` поиска и og:image; Dribbble режет частые открытия - паузы 15-20 с.
