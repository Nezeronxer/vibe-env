## Что должно заработать

В рое лимит одной полосы ставит на паузу только её. «Расходы» показывают таблицу день × проект: деньги и токены. «Собрать отчёт об ошибке» кладёт zip только с техническим в папку. Есть файловый лог приложения. Плашка «Вышла версия X» по адресу обновлений; без адреса выключено и сказано почему.

## Из брифа, дословно

> «Лимит у одного агента роя… ставит на паузу всю задачу. Менять?» → «Стоит только он»
> «Обновление самой программы… Как?» → «Плашка со ссылкой»
> «История расходов… Что добавить?» → «Таблица по дням»
> «Кнопка «Собрать отчёт об ошибке»… Делать?» → «Да»; «Что класть в архив?» → «Техническое»

## Критерии приёмки

- [ ] Тест: лимит полосы A - полоса A ждёт с `resume_at`, B работает; все полосы на паузе - задача `PausedLimit`; после сброса A продолжает
- [ ] В дорожках роя у полосы «ждёт лимит до HH:MM»
- [ ] `spend_history`: день, проект, среда, usd, токены вход/выход; чат - отдельной строкой; «нет данных» вместо 0 у сред без денег; хранение 400 дней со свёрткой в месяцы; экран «Расходы» с пустым состоянием
- [ ] `<data>/logs/app.log` с ротацией 5×1 МБ, без текстов сообщений
- [ ] Отчёт об ошибке: zip по белому списку (версии, ОС, CLI, настройки без секретов, состояния задач без текстов, хвост лога, файл «что внутри»); тест: подложенные токен и текст чата не попадают в zip
- [ ] Плашка обновления: раз в сутки и по кнопке в «О программе»; закрытая не возвращается до новой версии; без `release_feed` проверка выключена, сказано «адрес обновлений не задан»; ошибка сети - молча, время и ошибка в «О программе»; тест без сети
