## Что должно заработать

Спека: истории 278-284 (GitHub), 305-312 (приёмы, `research-youtube.md`), 292 (тело коммита); границы `core::git` v4.

**GitHub.** `publish` - проверка защищённых путей во всей истории (правило F1) до отправки, затем `gh repo create <имя> --private|--public --description --source <путь> --push`; результат - URL; ошибки ключами: `gh_missing`, `gh_not_logged_in`, `name_taken`, `protected_in_history{paths}`. `log_page(skip, limit)` - коммиты с родителями, ссылками (ветки/теги), автором, временем, дорожками графа и рёбрами, считается порциями; коммиты задач узнаются по трейлерам/ветке `ns/*`. `revert_commit` - локальный `git revert` (запушенный - как действие наружу по D01). Команды `gh_publish/git_log_page/git_revert_commit` - настоящие.

**Приёмы (305-312):** доля занятого контекста сессии из событий CLI (где есть; иначе `None`) в `Task`/чат-событии; команда «Сжать» с текстом → `/compact <текст>` для сред, где есть; «стартовый налог» - оценка токенов CLAUDE.md/AGENTS.md + схем MCP + строк описаний скиллов/агентов, предупреждение > 200 строк; передаточная записка в копии задачи перед сменой модели / запасной по лимиту / сжатием, первой строкой промпта следующего запуска; сжатие вывода команд в контекст агента (повторы, прогресс-бары → счётчик), сырой вывод при ошибке - файл в копии и путь агенту; порты и база на копию (`PORT`, `NIGHTSHIFT_PORT_BASE`, имя базы) по флагу проекта; подготовка копии одним шагом с временем в ленте; умолчания моделей служебных ролей (Надзиратель, Координатор очереди, переписывание промпта) - быстрая модель среды; заранее разрешённые инструменты по ролям способом CLI (`--allowedTools` и аналоги из `research-clis.md`).

**Ремонт по приёмке (292):** тело итогового коммита задачи - первый абзац отчёта, обрезка по границе предложения ≤ 500 символов с «…», не на полуслове.

## Критерии приёмки

1. `publish` на временном репозитории с фейковым `gh` (скрипт в PATH теста): правильные аргументы; `.env` в истории → `protected_in_history`, `gh` не вызван.
2. `log_page` на репозитории с ветками и слиянием: дорожки и рёбра верны, 2 порции по 200 = одна на 400.
3. Записка: смена модели в задаче на `FakeAdapter` → файл записки в копии, следующий промпт начинается с неё.
4. Сжатие вывода: 500 одинаковых строк → счётчик; код выхода ≠ 0 → путь к сырому выводу в контексте агента.
5. Порты: две задачи проекта с флагом получают разные `PORT`; без флага - не задаются.
6. Тело коммита из отчёта длиной 2000 символов обрезано по предложению, без обрыва слова.
7. `cargo test --workspace` зелёный, clippy чист.
