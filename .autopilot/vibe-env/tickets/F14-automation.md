# F14 - Автоматика: расписание задач, предложенные задачи, сторож красного CI

**Общее:** `_v5-common.md`. **Фишки:** #1, #7, #2 из research-v5-features.md.
**Зона:** новые модули ядра `core/src/schedule/`, `core/src/suggest/`, `core/src/ci/` (или в `app/src/` по образцу `presence.rs`/`updates`), `core/src/lib.rs` и `model.rs` (точечно), `app/src/main.rs` (точечно), новый экран `ui/js/v4/automation.js` + `ui/css/v4-automation.css`, `ui/js/v4/i18n-auto.js`, кнопка входа рядом с «Фабрика»/«Настройки» (в `ui/js/shell.js` точечно), Фабрика - только ссылка.

1. **Расписание (#1).** Экран «Расписание»: задача (текст, проект, среда, модель, Качество) + пресет (ежедневно в ЧЧ:ММ, по будням, раз в неделю) + вкл/выкл. Шаблоны: «Обновить зависимости», «Аудит безопасности», «Добить TODO», «Почистить мёртвый код». Срабатывание = обычная задача через существующий `submit_task` (worktree, Качество, ворота), без пуша; результат и находки - в «Ждёт тебя»/ленту. Пропущенное срабатывание (мак спал) - один раз при пробуждении, не пачкой. Хранение - в конфиге/хранилище приложения. Лимиты: не запускать, если лимит среды < 10% (есть `limits`).
2. **Предложенные задачи (#7).** По кнопке «Найти, что сделать» (и опционально по расписанию) - быстрый проход без модели: TODO/FIXME/XXX/HACK в отслеживаемых файлах проекта (`git grep`), падающие/пропущенные тесты не трогать; карточки «Предлагаю» (файл:строка, текст, предложенная формулировка задачи). «Сделать» = `submit_task`, «Не предлагать такое» = запомнить отпечаток и не показывать. Список в экране автоматики и счётчик на кнопке.
3. **Сторож CI (#2).** Для задач, которые человек уже запушил/открыл PR (есть `publish`/PR-данные): опрос статуса через `gh` (если есть `gh` и вход; нет - понятная подсказка, фича выключена) раз в ~60 с только пока есть открытые PR. Красный CI или конфликт → новая задача «Починить CI: <PR>» с логом упавшей проверки (`gh run view --log-failed`, урезанно), лимит попыток (настройка, по умолчанию 2), не вмешивается в задачу, которая сейчас работает. Пуш починки - по общей политике (с разрешения). Тумблер «Слить, когда зелёное» - по умолчанию выкл, при вкл - `gh pr merge --auto` только с подтверждения в первый раз.

**Критерии:** Rust-тесты: следующее время срабатывания для трёх пресетов (включая переход через полночь и выходные), одно догоняющее срабатывание после сна; разбор `git grep` в карточки и фильтр «не предлагать»; машина состояний сторожа (зелёный → ничего, красный → задача, лимит попыток, занятая задача → ждать) на заглушке `gh`. Selftest: экран расписания (создать/выключить), список «Предлагаю», статус сторожа. Снимки f14-after. Общие проверки зелёные.
