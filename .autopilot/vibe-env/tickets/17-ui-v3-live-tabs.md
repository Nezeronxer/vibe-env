## Критерии приёмки

1. `selftest` пополнен чистыми функциями: разбор разметки (жирный, блок кода, список, ссылка `javascript:` не становится ссылкой), склейка чтений, сворачивание вывода, разбор унифицированного диффа в строки с номерами, сохранение/восстановление вкладок, проверка занятости клавиш - всё зелёное.
2. На `dev-mock.js`: задача показывает поток Read → Edit с диффом → Bash с выводом → ошибка инструмента → ответ печатается; индикатор меняет глагол; свёрнутое раскрывается.
3. Две вкладки с задачами идут одновременно, ⌘D ставит их рядом, у каждой своё поле и индикатор; ⌘W закрывает вкладку, работа продолжается; перезапуск восстанавливает вкладки.
4. Первый запуск: один шаг папки, среда и модель выбраны сами; без сред - экран установки; описания моделей по-русски, ни одного сырого ключа на экранах (проверка: обход всех экранов в ru и en не находит текста вида `слово.слово` или `snake_case` из словаря).
5. Ширина 900 и 1400 px - ничего не налезает; тёмная и светлая темы.
6. `node scripts/ui-selftest.js` зелёный; `cargo test --workspace` и clippy не сломаны правкой строк моделей.
