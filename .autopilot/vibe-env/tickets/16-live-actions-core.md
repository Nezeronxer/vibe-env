## Критерии приёмки

1. Разбор потока Claude по записанному примеру (фикстура stream-json с Read, Edit, Bash с выводом, ошибкой инструмента, частичными сообщениями): события `Action` старт+результат с верными `ActionInput`, `output`, `ok`; `TextDelta` собираются в тот же текст, что итоговое сообщение.
2. Edit/MultiEdit/Write → `diff` унифицированного вида; тест на многострочную правку и новый файл.
3. Адаптер без текста правки (заглушка CLI): после шага в ленте `Edit` по каждому изменённому файлу с `git diff`.
4. Вывод > 64 КБ и дифф > 200 КБ обрезаны с пометкой; значение секрета из связки ключей в выводе команды заменено на `${ИМЯ}` и в логе, и в событии окна.
5. Перезапуск движка: `get_task_log` отдаёт действия с выводом и диффом; старые логи без `action` читаются.
6. События окна склеиваются: 500 строк вывода за 100 мс дают не больше 3 событий на задачу.
7. Описания встроенных моделей (`builtin_models` во всех адаптерах) - ключом словаря `model.desc.<id>` в `blurb`, пометка источника («Anthropic docs, дата; не сверено с CLI») - отдельным полем `source_note`; тест на ключи.
8. Полный `cargo test --workspace`, clippy `-D warnings`, `cargo build -p nightshift-app` - зелёные; сборка UI не ломается (`node scripts/ui-selftest.js`).
