Как-то вот так вот, и где ползунки, роя и фабрики? Куда ты их убрал? Где сами настройки? Как это настраивать? Если возможно, переделай это как-то немножечко более понятным, понятнее пользователю.»

Разбор оркестратора (проверено вживую в .app feda8fc и в коде):
- `ui/css/v4-shell.css:61` `.composer .tg .sw { display: none; }` - у «Качество» и «Рой» спрятаны тумблеры, остались слова с подчёркиванием; включено или нет - не видно. «⋯» - единственный вход в настройки качества/роя, без подписи.
- Боковой рейл с «Фабрикой» и «Настройками» в v4 не показывается (story 246, ⌘B прячет чаты); настройки и фабрика доступны только через ⌘K - пользователь о них не знает.
- Вкладка чата с Claude Code и вкладка терминала с Claude Code обе с крабом. ⌘T открывает чат, «>_ Claude Code» в строке состояния - терминал. Завершившийся процесс в терминале оставляет только серую строку «Enter - перезапустить».

## Что должно заработать

1. **Поле ввода.** «Качество» и «Рой» - видимые переключатели: маленький тумблер + слово (тумблер `.sw` уже есть в разметке, его прячет CSS). У каждого `title` одной фразой, что он делает (Качество - «план, тесты до кода, ревью перед merge»; Рой - «несколько агентов решают одну задачу, лучшее берётся»). «⋯» заменить на кнопку со значком шестерёнки и словом «Настроить» (на узкой панели допускается только значок, но с `title`). Высота и тишина поля ввода сохраняются - без пёстрых кнопок-таблеток.
2. **Вход в настройки и фабрику всегда на виду.** Справа в полосе вкладок (рядом с Clawd) две тихие кнопки со значком и подписью: «Фабрика» и «Настройки» (на узком окне - только значки с `title`). Там же или в строке состояния - «⌘K Команды», по клику открывает палитру. ⌘, открывает настройки (проверить, что работает на маке; если меню приложения перехватывает - пункт «Настройки…» в меню приложения).
3. **Чат и терминал различимы.**
   - Вкладка/шапка терминала - значок `>_`, вкладка чата - значок среды (краб). Имя терминальной вкладки «Терминал · Claude Code», у чата - тема чата.
   - «+» открывает маленькое меню (тот же вид, что меню модели F7): «Новый чат ⌘T», «Терминал с Claude Code», «Терминал (shell)» с сочетаниями справа.
   - Кнопка в строке состояния «>_ Claude Code» → подпись «>_ Терминал», `title` «Открыть Claude Code в терминале». Клик всегда видимо открывает или переводит фокус на терминальную вкладку.
   - Терминал, где процесс завершился: по центру вывода понятная плашка «Claude Code закрыт» и кнопки «Запустить снова» и «Закрыть вкладку» (Enter и ⌘W по-прежнему работают).
4. Пустой экран нового чата: одна строка подсказки внизу «Чат - вопросы и задачи агенту. Нужен сам Claude Code в терминале - «+» → Терминал».

## Чего не делать
- Не трогать ядро (Rust) и форматы конфига. Не возвращать весь старый рейл.
- Без кремового фона, кнопок-таблеток, моноширинных подписей-меток, длинных тире. Тексты - коротким дефисом.
- Не ломать сочетания и проверки F5/F7.

## Критерии приёмки
1. Selftest: тумблеры «Качество»/«Рой» видимы (ненулевой размер `.sw`), клик меняет `aria-checked` и сохраняет `last_quality.on`/`last_swarm`; у обоих есть `title`.
2. Selftest: кнопки «Фабрика» и «Настройки» в полосе вкладок видимы и ведут на свои экраны; «⌘K Команды» открывает палитру.
3. Selftest: «+» открывает меню из трёх пунктов; «Терминал (shell)» открывает вкладку терминала со значком `>_`, «Новый чат» - вкладку чата со значком среды.
4. Selftest: после выхода процесса в терминале видны «Запустить снова» и «Закрыть вкладку», первая перезапускает процесс.
5. Снимки «после» тёмная/светлая, окно 1440×900 и 960×680: поле ввода, полоса вкладок с кнопками, меню «+», завершённый терминал - в `.autopilot/vibe-env/screens-v2/f8-after/`, просмотрены глазами.
6. `node scripts/ui-selftest.js` (с `NS_PLAYWRIGHT` тоже) и `cargo test --workspace` - зелёные.
