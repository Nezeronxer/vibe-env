## Что должно заработать

Вести скиллом `taste` (как таск 22). Спека: истории 250-265, 298-299, 301-302; границы `core::term`/`app` (`term_*`, `window_*`, `term-exit`, `cli-updated`) и точки расширения таска 22 (`INTERFACES` в `interfaces.md`).

Вид панели `term`: xterm 6 с аддонами (WebGL, запасной DOM), тема из `theme.js`, вывод из канала `ArrayBuffer`, `ack` раз в ~100 КБ, resize через fit; поиск ⌘F, ссылки http/https/file, `путь:строка` с ⌘ - в редактор, копирование выделением, ⌘C/⌘V, OSC 52 выключен по умолчанию. ⌘⇧T - терминал (shell в папке проекта). «Открыть <Среда> в терминале» (палитра, бар) - CLI среды с моделью; у вкладки значок среды и состояние (как herdr); «Продолжить в терминале» открывает встроенную вкладку (системный - настройка «Внешний терминал»). Выход процесса - строка «[процесс завершился, код N] Enter - перезапустить», ошибка PTY - причина. Закрытие с процессом - вопрос. `cli-updated` → полоса «<Среда> обновлена до X - перезапустить вкладку». Вынести/вернуть окно, ⌘N, отключить окно ⌘⇧W, список сессий в палитре (attach). Ввод во все панели ⌘⌥I (полоса акцентом). Выделение → «Спросить агента» / «Поручить». Долгая команда > 10 с вне фокуса - уведомление. Глобальная клавиша ⌃` (через `app`, настраивается). Префикс-режим tmux (`prefix = ctrl+b` в конфиге): `%` `"` стрелки `z` `c` `d` `0-9`. Раздел настроек «Терминал» (через реестр): темы (Nightshift + Catppuccin Mocha, Tokyo Night, Gruvbox Dark, Dracula, Solarized Light, One Dark - значения из официальных репозиториев, источники в `docs/themes-sources.md`), свои цвета, шрифт, размер, интервал, лигатуры, курсор, история, отступы; импорт Ghostty/kitty/iTerm2. `mock-term.js` - эхо-терминал для браузера без Tauri.

## Критерии приёмки

1. selftest: разбор тем Ghostty/kitty/iTerm2 (и отказ на чужом файле), префикс-автомат клавиш, разбор `путь:строка:кол`, расписание ack - зелёные.
2. В настоящем окне (`cargo tauri dev`): shell, `vim`, `htop`, интерактивный `claude` в панели; сплит терминал + агент; тема меняется вживую.
3. Вынести вкладку в окно и вернуть - вывод и процесс на месте; закрыть окно - сессия в списке палитры, attach возвращает её.
4. Имитация `cli-updated` даёт полосу «перезапустить вкладку», перезапуск запускает CLI заново в той же папке.
5. Скриншоты (Playwright на `mock-term.js` и живые) - в отчёт.
