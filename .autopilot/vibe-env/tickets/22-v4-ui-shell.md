4. ⌘B, ⌘K, ⌘D, ⌘⇧D, ⌘⇧Enter, ⌘W, ⌥⌘1…7 работают на `dev-mock`.
5. ru-словарь без «Ворота», «Влив», «Наборы» в видимых строках (selftest).
