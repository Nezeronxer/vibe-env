## Критерии приёмки

1. selftest: автомат состояний Clawd (приоритеты, «радуется» гаснет через 2 с), шаг анимации по времени не зависит от частоты кадров, остановка при `visibilitychange` - зелёные.
2. Playwright: `?fps=1` показывает ≥ 58 кадров/с при работе ленты; скриншоты каждого состояния - в отчёт.
3. На `mock-clawd.js`: событие новой модели → всплывашка «теперь X» с «Вернуть»; полоса контекста 75% → подсказка и «Сжать».
4. Рой на `dev-mock`: отправка с включённым «Роем» показывает «· рой» и дорожки.
