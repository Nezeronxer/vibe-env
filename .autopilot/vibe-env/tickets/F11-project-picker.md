# F11 - Проект выбирается явно: открыть папку из Finder или создать новый

**Требования:** G07 (проекты), просьба пользователя 23.10
**Зависит от:** F10
**Зона:** `ui/js/core/projects.js` · `ui/js/screens/chat.js` (только выбор проекта в новом чате и шапке) · `ui/js/v4/term.js`, `ui/js/v4/publish.js`, `ui/js/v4/history.js`, `ui/js/shell.js` (только откат на `projects[0]`) · `app/src/proj.rs`, `app/src/main.rs` (новая команда создания проекта) · `ui/js/core/api.js` · i18n · `ui/dev-mock.js` · `ui/css/chat.css` · тесты `app/` и `scripts/ui-selftest.js`, `ui/selftest.js`
**Волна:** 21
**Ревью:** да
**Модель:** сильная

## Из брифа, дословно (пользователь, 23.10)

> «Я бы хотел, чтобы ты ещё добавил такую вещь, чтобы можно было спокойно выбирать проект, а он не создавал его автоматически, то есть, когда ты хочешь что-то забрать, ты либо выбираешь проект, либо создаёшь. Выбираешь ты его из своего проводника, из своего компьютера.»

Сейчас (проверено в коде): новый чат молча берёт `S.lastProject || default_project || S.projects[0]`; в выпадающем списке шапки есть «Добавить проект…» (`chat.add_project`), диалог папки и `init_repo` уже есть в `ui/js/core/projects.js`; создать новый проект с нуля нельзя.

## Что должно заработать
1. **Новый чат без проекта не начинается молча.** На пустом экране «Что сделать?» над полем - заметный выбор проекта (кнопка-меню в стиле меню модели F7, мир F10): «Проект: billing-api ⌄». Если проектов нет или пользователь ещё не выбирал в этом окне - кнопка говорит «Выбрать проект» и отправка задачи («Сделай…») просит выбрать проект (поле не блокируется для вопросов без проекта, если ядро это умеет; если нет - просит выбрать).
2. **Меню проекта:** недавние проекты (имя + путь мелко, ветка), затем «Открыть папку…» (системный диалог выбора папки - тот же, что уже есть) и «Создать проект…».
3. **«Создать проект…»:** системный диалог выбора папки-родителя → поле имени (латиница/кириллица, без `/`) → создаётся папка, `git init`, первый пустой коммит (чтобы worktree работали), проект добавляется и выбирается. Новая команда ядра `create_project { parent, name }` в `app/src/proj.rs`: проверка имени (нет `..`, `/`, пустого, существующей папки), без перезаписи; ошибки по-человечески.
4. Папка без git при «Открыть папку…» - как сейчас: спросить «Сделать git-репозиторием?».
5. Убрать молчаливый откат на `S.projects[0]` там, где он решает за пользователя, куда пойдёт задача (новый чат, терминал «+» → терминал открывается в выбранном проекте или спрашивает). Последний явный выбор (`lastProject`) запоминается и предлагается, это не «автоматически».
6. Вид - мир F10 (`.impeccable/surfaces/ui-index-html.md`), стандартные контролы.

## Чего не делать
- Никаких автосозданий папок/репозиториев без явного действия пользователя.
- Не трогать существующие проекты на диске, не удалять.

## Критерии приёмки
1. Rust-тесты `create_project`: создаёт папку с git и одним коммитом; отказ на `..`, `/`, пустое имя, существующую папку.
2. Selftest: новый чат на чистом старте (нет `lastProject`) показывает «Выбрать проект»; «Сделай…» без проекта не отправляется и открывает меню проекта.
3. Selftest: меню проекта - недавние, «Открыть папку…», «Создать проект…»; выбор недавнего меняет проект чата.
4. Снимки «после» тёмная/светлая 1440 и 960: пустой чат с кнопкой проекта, открытое меню, форма создания - в `.autopilot/vibe-env/screens-v2/f11-after/`, просмотрены.
5. `node scripts/ui-selftest.js` (с `NS_PLAYWRIGHT`) и `cargo test --workspace` - зелёные.
