# F15 - Доказательство работы и превью приложения с инспектором

**Общее:** `_v5-common.md`. **Фишки:** #3, #10 из research-v5-features.md. **Зависит от:** F13 (движок задач).
**Зона:** `core/src/engine/` (новый шаг ворот), `app/src/` (окно/вкладка превью, захват), `ui/js/v4/preview.js`, `ui/css/v4-preview.css`, `ui/js/screens/taskcard.js` (вложения отчёта), `ui/js/v4/i18n-preview.js`, `app/src/main.rs`/`api.js`/`index.html` точечно.

1. **Превью (#10).** Вкладка «Превью» у задачи/проекта: адрес dev-сервера (порт задачи, если ядро его знает; иначе поле адреса `http://localhost:…`, только localhost/127.0.0.1). Отдельное Tauri-окно/webview (не iframe в основном окне с нашим CSP), кнопки: обновить, ширина (телефон 390 / планшет 768 / десктоп), «Указать элемент»: клик по элементу в превью → в поле ввода чата задачи вставляется ссылка на элемент (селектор, текст, размер) как контекст. Инжект скрипта выбора - только в окно превью, только localhost.
2. **Доказательство (#3).** Необязательный шаг ворот «Проверить как пользователь» (настройка проекта, по умолчанию выкл): если в проекте задан скрипт/команда запуска и адрес - после проверок открыть приложение в скрытом webview/Playwright (если есть в системе; если нет - шаг пропускается с пометкой), снять 3-5 скриншотов главного сценария (страница, после клика по основной кнопке, мобильная ширина) и приложить к отчёту «задача готова» в карточке (лента миниатюр, клик - крупно). Видео - не обязательно; если без новых зависимостей нельзя - только скриншоты, и это в CONCERNS.

**Критерии:** Rust-тесты: шаг ворот выключен по умолчанию; при выключенном/недоступном захвате задача не падает; адреса не-localhost отклоняются. Selftest (dev-mock): вкладка превью открывается, «Указать элемент» вставляет описание элемента в поле; карточка с вложенными скриншотами. Снимки f15-after. Общие проверки зелёные.
