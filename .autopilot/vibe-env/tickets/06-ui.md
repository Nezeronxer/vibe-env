## Что должно заработать

Один `index.html` + `app.js` + `style.css` + `i18n.js` (ru/en по `navigator.language` или настройке), без фреймворка. Вызовы - `window.__TAURI__.core.invoke` и `window.__TAURI__.event.listen` (`withGlobalTauri: true`). Для просмотра в обычном браузере - `dev-mock.js`, подключается только если `window.__TAURI__` нет: фейковые проекты/задачи во всех статусах, чтобы каждый экран можно было открыть и снять скриншот.

**Главный экран.** Слева - проекты (имя, точка статуса, бейдж «ждёт тебя»), внизу «+ Добавить проект» и зона перетаскивания папки. Справа сверху - поле задачи (многострочное, ⌘/Ctrl+Enter - поставить, выбор движка рядом, черновик сохраняется), под ним группы: **Нужен ты** (выделена, вопрос прямо в строке с кнопками вариантов и полем ответа; «Запушить?» с двумя кнопками), **В работе** (стадия и время), **В очереди**, **Готово** (итог одной строкой: резюме · файлов · тесты · ревью · коммит; «Откатить»), **Не вышло** (причина; «Повторить», «Удалить»), свёрнутый **Архив** (старше 7 дней). Пустые группы скрыты. Шапка проекта: путь, `origin: … · main ↑N ↓M`, кнопки «Запушить main», «Обновить». Глобально: кнопка паузы.

**Карточка задачи** (панель справа по клику): заголовок, ветка, движок, этапы-таймлайн с временем, живой лог (по строке: сообщения агента, инструменты, проверки, ревью, git; автопрокрутка, если внизу), «Изменения» (файлы +/-), вывод тестов, замечания ревью, время и число попыток/кругов, кнопки по статусу: Ответить / Отменить / Повторить / Удалить / Откатить / Повторить push / Открыть папку / редактор / терминал / ссылка на PR.

**Первый запуск / пусто:** нет проектов → крупная зона «Перетащи папку проекта» + кнопка; движок по умолчанию недоступен → карточка «Установи Claude Code: …» с подсказкой из `list_agents`. Папка без git → «Сделать git-репозиторием?» (кнопка → `init_repo`).

**Настройки проекта:** имя, команда проверки и подготовки (с автоопределёнными значениями), файлы для копирования, финиш (локально / push / PR), «спрашивать перед действиями наружу», движок исполнителя, движок ревьюера, запасной движок на случай лимита (по умолчанию - нет). **Общие настройки:** параллельность, язык, горячая клавиша, свои команды-движки (добавить/удалить, шаблоны с подсказкой `{prompt} {cwd} {session}` и предупреждением «без ограничений прав»), Telegram (вкл., поле токена - type=password, сохраняется через `set_tg_token` и не показывается обратно; код привязки и статус; прокси; время сводки).

Тёмная/светлая тема по системе. Дизайн - спокойный, плотный, как инструмент разработчика: системный шрифт, без кремового фона, без курсивных акцентов в заголовках, без меток 01/02/03, без кнопок-таблеток, без градиентов. Статусы - цветом и текстом (не только цветом). Клавиатура: Tab-порядок, Esc закрывает карточку, `/` фокус в поле задачи.
