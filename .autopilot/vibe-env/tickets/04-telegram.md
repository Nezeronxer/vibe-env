## Что должно заработать

`Telegram::start` поднимает поток long polling (`getUpdates`, таймаут 50 с) через `reqwest` blocking с прокси из настроек или `HTTPS_PROXY`. Привязка: `pairing_code()` - 6 цифр, живёт 10 минут; `/start <код>` из любого чата → `on_paired(chat_id)`, бот отвечает «Привязано». Всё, что приходит не из `chat_id`, игнорируется (кроме `/start <верный код>`).

Как `Notifier`: `Question` - текст + inline-кнопки вариантов (callback_data = короткий id задачи + индекс), подсказка «или ответь на это сообщение»; `Outward` - кнопки «Запушить»/«Не надо»; `Failed`, `Done`, `Limit` - текст (Done - с `disable_notification`). Запоминает message_id ↔ task_id, чтобы reply на сообщение был ответом на вопрос этой задачи (`Control::answer`). Кнопки → `answer`/`approve_outward`, после нажатия кнопки убираются и сообщение дописывается выбранным.

Команды: `/new <текст>` и `/new <проект>: <текст>` → `Control::submit`; `/status` → `status_text`; `/digest` → `digest_text`; ежедневная сводка в `digest_at`, если задано. Язык сообщений - из `Settings.language` (auto → ru, если локаль ru).

Токен - `load_token/save_token` через `keyring` (сервис `nightshift`, пользователь `telegram-bot-token`), запасной вариант - файл 0600 в каталоге данных; токен никогда не пишется в лог и в ошибки (маскировать в тексте ошибок reqwest - URL содержит токен!). `status()` - «connected @bot», «no token», «network error: …», «invalid token».

## Критерии приёмки

- [ ] Тест (локальный HTTP-сервер-заглушка Bot API на `127.0.0.1`, базовый URL подменяем): привязка по верному коду, отказ по неверному/просроченному
- [ ] Тест: сообщение из чужого chat_id не доходит до `Control`
- [ ] Тест: `Question` с вариантами → кнопки; callback → `Control::answer(task, вариант)`; reply на сообщение-вопрос → `answer(task, текст)`
- [ ] Тест: `/new proj: сделай X` → `submit(Some("proj"), "сделай X")`; `/status` отвечает текстом из `status_text`
- [ ] Тест: текст ошибки сети не содержит токен (маскирование)
- [ ] Нет сети / неверный токен → поток не падает, `status()` с причиной, повтор с паузой (экспоненциально до 60 с)
