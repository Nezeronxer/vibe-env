## Что должно заработать

В «Предлагаю» рядом с TODO - открытые issues проекта с GitHub; «Сделать» делает из issue задачу (текст issue - данные), после слияния приложение спрашивает «Закрыть issue #N?». В проекте видны прошлые сессии Claude Code из терминала; «Продолжить» открывает сессию как обычную задачу в отдельной git-копии.

## Из брифа, дословно

> «Задачи из GitHub Issues… Делать?» → «Да, закрытие с вопросом»
> «Issues с GitHub - откуда и когда подтягивать?» → «Вместе с ночным «Предлагаю»»
> «Подхват старых сессий… Делать?» → «Да»
> «Продолжение старой сессии… Где её продолжать?» → «В отдельной копии»

## Критерии приёмки

- [ ] `gh issue list` (заглушка `Gh` в тестах) даёт карточки «issue #N» со ссылкой; только проекты с GitHub-ремоутом; нет `gh`/входа - тихая строка с причиной, TODO работают
- [ ] «Сделать» по issue - задача с текстом issue в разметке данных; «не предлагать» помнит issue
- [ ] Слитая задача из issue - вопрос «Закрыть issue #N?» в «Нужен ты»; закрывает только после «Закрыть»; тест без ответа - ничего не закрыто
- [ ] `sessions::list(project)` читает заголовки `~/.claude/projects/<ключ>/*.jsonl` (ключ сверен по живому каталогу), страницы по 50, битые строки/файлы не роняют список; пусто - понятный текст
- [ ] «Продолжить» создаёт задачу в git-копии и продолжает сессию `--resume`; если CLI ищет сессию по cwd - файл копируется в ключ копии, исходник не меняется (тест на временном HOME)
