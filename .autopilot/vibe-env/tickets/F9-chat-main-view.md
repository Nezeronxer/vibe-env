## Что должно заработать

1. **Лента по центру.** Колонка сообщений макс. ~760 px по центру панели (на узкой панели - во всю ширину с полями 16 px). Текст сообщений и ответов - **обычный пропорциональный шрифт** (системный sans), 14-15 px, межстрочный ~1.55. Моноширинный - только код, пути файлов, диффы, команды, терминал.
2. **Сообщения.** Мои - справа, тёмно-серый (светлая тема - светло-серый) пузырь со скруглением ~14 px, без аватара. Ответы агента - без пузыря, на всю ширину колонки; над ответом одна тихая строка: значок среды/роли · имя роли · модель (мелко, бледно), время - справа при наведении.
3. **Действия агента - лесенкой и свёрнуто** (pin-30). Каждый вызов инструмента - одна тихая строка со значком: «Прочитал calc.py», «Изменил test_calc.py +1 −0», «Запустил pytest · 7 из 9». По клику раскрывается: дифф (тонированные + / −), вывод команды, параметры. Подряд идущие действия одной роли - одна группа «3 действия» со сворачиванием. Ошибки (упавшая команда) - строка красным значком, раскрыта по умолчанию только если это последнее событие. Сейчас диффы и вывод развёрнуты всегда - так больше не надо.
4. **«Думаю…»** - одна строка с мягкой пульсацией точки, пока агент работает и ещё не прислал текст.
5. **Поле ввода** (pin-76, Vibecode): капсула/скругление ~16 px, внизу панели по центру колонки, высота от 1 до ~8 строк. Сверху - текст, снизу ряд: слева модель (меню из F7), тумблеры «Качество» и «Рой», «⚙ Настроить» (из F8); справа круглая кнопка ↑ (акцент), во время работы агента - квадрат «Стоп» (если есть активная задача/запуск - вызывает существующую отмену; нет такой команды - кнопка не показывается). Под полем мелко: «Enter - отправить · Shift+Enter - новая строка». Плейсхолдер короче: «Что сделать?».
6. **Плашка над полем** (pin-85): пока агент работает - «Исполнитель · правит src/cursor.py» + «Стоп»; данные из существующей ленты событий, без новых команд ядра.
7. **Пустой чат** (pin-25): по центру крупно «Что сделать?» (без шаров/неона), под ним то же поле ввода и 3-4 примера кнопками (уже есть: «Сделай…», «Найди и почини…», «Объясни, как устроен…») - тихие карточки в ряд.
8. **Список чатов слева - виден по умолчанию** (как `body.side-on`, ширина ~240 px), группы «Ждёт тебя / Работает / Готово» (или текущая группировка, если она уже такая), сверху «+ Новый чат», скрывается ⌘B и кнопкой. Выбор сохраняется (`ns.side`), но новый пользователь без сохранённого значения видит список.
9. **Карточка задачи («Ждёт тебя», этапы План…Merge)** не убирается, но становится компактнее: одна строка этапов + вопрос с кнопками, не на всю ширину окна, а в колонке ленты.
10. Терминал, Фабрика, Рой, вкладки, палитра, меню «+» - работают как после F8.

## Чего не делать
- Не трогать ядро (Rust), команды API и форматы.
- Анти-слоп (обязательно): без кремового фона, без курсивных акцентных слов в заголовках, без меток 01/02/03, без моноширинных подписей в интерфейсе, без кнопок-таблеток повсюду, без градиентов, неона, светящихся шаров и аватаров-сфер. Один акцентный цвет на экран. Тексты - короткий дефис `-`.
- Не ломать F5/F7/F8 и их проверки.

## Критерии приёмки
1. Selftest: ширина колонки ленты ≤ 780 px на окне 1440; шрифт текста ответа не моноширинный, а у блока кода/диффа - моноширинный.
2. Selftest: в ленте демо-чата вызовы инструментов свёрнуты (дифф не виден), клик раскрывает дифф; группа из нескольких действий сворачивается в одну строку.
3. Selftest: мои сообщения выровнены вправо и в пузыре; ответ агента без фона.
4. Selftest: пустой чат показывает «Что сделать?», поле и примеры; клик по примеру ставит текст в поле (не отправляет).
5. Selftest: на чистом старте (`ns.side` не задан) список чатов виден; ⌘B прячет, перезагрузка помнит.
6. Снимки «после» в `.autopilot/vibe-env/screens-v2/f9-after/`: демо-чат, пустой чат, раскрытый дифф, агент работает (плашка + Стоп) - тёмная и светлая, 1440×900 и 960×680. Просмотрены глазами, минимум два круга «снял - посмотрел - поправил». Рядом с каждым снимком мысленно сравнить с pin-29/pin-25/13-claudecodeui - выглядит ли так же чисто.
7. `node scripts/ui-selftest.js` (с `NS_PLAYWRIGHT` тоже) и `cargo test --workspace` - зелёные.
