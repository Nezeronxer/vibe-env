# F12 - Чат: очередь сообщений и «Сразу», боковой вопрос, подсказка следующего шага, «Выполнить» у команды; ошибка остановленного запуска

**Общее:** `_v5-common.md`. **Фишки:** #8, #9, #11, #12 из research-v5-features.md + баг.
**Зона:** `ui/js/screens/chat.js`, `ui/js/screens/composer.js`, `ui/js/core/actions.js`, `ui/css/chat.css`, `ui/css/live.css`, новый `ui/js/v4/sidechat.js`, `ui/js/v4/i18n-chatx.js`; ядро - `core/src/chat/` (боковой вопрос, подсказка, разбор ошибки), команды в `app/src/main.rs`.

1. **Очередь (#8).** Пока агент чата/задачи работает, отправленное сообщение встаёт в очередь (видно серым «в очереди», можно править/удалить до прочтения). Рядом с отправкой - «Сразу»: прерывает текущий шаг и передаёт сообщение (через существующие `note`/`cancel`/`answer`; если ядро умеет только «к следующему запуску» - «Сразу» = отмена текущего запуска + сообщение первым в следующем). Прочитанное агентом перестаёт быть серым.
2. **Боковой вопрос (#9).** ⌘; (и кнопка в шапке чата) открывает узкую панель «Спросить» справа: короткий отдельный запуск среды только на чтение (как текущий чат-вопрос, `--permission-mode plan`) с контекстом задачи (тема, последние действия, дифф кратко); ответы не пишутся в историю задачи и не будят исполнителя.
3. **Подсказка следующего шага (#11).** После ответа/готовой задачи в пустом поле серым - одна предложенная реплика (из шаблонов по состоянию: «Запушить?», «Проверь на мобильном», «Напиши тесты на …»; без вызова модели - правила по событиям; модель - только если это дёшево и отключаемо). Tab принимает, любая клавиша прячет. Настройка «Подсказывать следующий шаг» (по умолчанию вкл).
4. **«Выполнить» у команды (#12).** У блоков shell-кода в ответах агента (```bash/sh/zsh/shell или `$ ` строки) кнопка «Выполнить»: команда открывается в терминале задачи/проекта (существующий `NS.term`), **не выполняется сама** - вставляется в терминал и ждёт Enter человека (защита от опасных команд). Вывод виден в терминале.
5. **Баг.** Остановленный человеком запуск показывает в ленте красным stderr CLI («claude.ai MCP servers blocked by enterprise policy…») как «Не ответил». Должно быть нейтрально «Остановлено» (если остановил человек), а настоящая ошибка - человеческим текстом; предупреждения CLI (`Warning:` в stderr) не считаются ошибкой ответа.

**Критерии:** selftest на каждую из 5 частей (очередь: серое → прочитано, «Сразу» вызывает отмену; панель ⌘; открывается и не добавляет сообщений в ленту задачи; Tab принимает подсказку; «Выполнить» вставляет команду в терминал без Enter; остановленный запуск = «Остановлено»); Rust-тест на разбор stderr-предупреждения; снимки f12-after; общие проверки зелёные.
