# 26 - Аудит безопасности v4 и живой прогон через computer use

**Требования:** G59, G04
**Зависит от:** 19, 20, 21, 23, 24, 25
**Зона:** `docs/security.md`
**Волна:** 15
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Ведёт оркестратор: аудит - Workflow независимых проверяющих по правилу `security-audit-every-new-project` (security-review, gitleaks, инъекции в команды - `curl`/`gh`/обновление CLI/PTY argv, загрузки из каталогов - пути, архивы, исполняемое, права окон и CSP Tauri, зависимости xterm/portable-pty), каждая находка - свежему перепроверяющему; подтверждённое - таски ремонта. `docs/security.md` - итог аудита v1-v3 (F1, F2, опровергнутое, gitleaks) и v4 (история 290). Затем живой прогон собранного `Nightshift.app` на маке через computer use по историям 243-312 (история 304); найденное - в ремонт до приёмки; скриншоты - в отчёт.

## Из брифа, дословно

> «Приложение тестируешь обязательно, обязательно через мой компьютер… полностью всё проверяешь через компьютер US» (G59)
> «проведи потом полный аудит безопасности, используя плагин для этого и скиллы» (G04)

## Критерии приёмки

1. `docs/security.md`: статус «проведён», дата, находки v1-v4 с починкой и опровергнутые.
2. Живой прогон: каждая история 243-312 отмечена «работает / ремонт / не проверить (почему)», скриншоты ключевых экранов.
