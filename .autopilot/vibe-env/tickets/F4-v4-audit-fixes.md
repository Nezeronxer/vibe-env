## Что должно заработать

Аудит v4 от 23.10: Workflow `wf_f4606ac4-f7b`, 5 проверяющих по `efcd705..HEAD`, каждую находку перепроверил свежий агент. Подтверждены четыре:

1. **medium - id моделей с models.dev не проверяются** (`core/src/models/radar.rs:27-38`, `chat_models`/`place`). Id `--yolo` из каталога становится семейством, потом значением `-m` у Qwen/Gemini, и CLI читает его как флаг (`qwen -m --version` печатает версию). Починка: отбрасывать id, не прошедшие `agent::adapters::common::is_model_id` (так уже делает путь списков CLI, `common.rs:266`). Второй рубеж: адаптеры не передают `-m`/`--model` с моделью, не прошедшей `is_model_id`.
2. **medium - скилл из каталога прячет `hooks`/`allowed-tools` YAML-экранированием** (`core/src/kits/units.rs:212-224`, `runs_in_markdown` ищет ключи регуляркой в сыром тексте). Такой скилл ставится как обычный markdown без галочки согласия. Новых зависимостей нет (YAML-парсера в проекте нет), поэтому починка закрытая по умолчанию: скилл считается `ScriptedSkill` (held), если во фронтматтере есть ключ, который не является простым идентификатором без кавычек (кавычки, `\`, `?`, якорь `&`/`*`, тег `!`, flow-mapping `{`), или если фронтматтер не разбирается построчно. Ключи сравнивать без учёта регистра и с `-`/`_` как одним знаком.
3. **low - снимок терминалов `terms.json` хранит до 2 МБ вывода на сессию открытым текстом с правами 0644 и не удаляется** (`app/src/ptycmds.rs:35-38`, `core/src/term/mod.rs:334-343`). Починка: запись 0600 (как в kits/secrets), удаление файла сразу после загрузки при старте.
4. **low - строки истории коммитов подделываются байтами 0x1E/0x1F в теме коммита** (`core/src/git.rs` ~755-772, `log_page`). «Откатить» на поддельной строке откатывает коммит, выбранный атакующим. Починка: записи через NUL (`-z` или `%x00`) и проверка каждой записи: 7 полей, sha - 40/64 hex, родители - hex через пробел, время - число. Неверные записи отбрасывать.
