# F13 - Задача: откат на любой ход, чек-лист перед мержем, «Забрать к себе / Отдать агенту»

**Общее:** `_v5-common.md`. **Фишки:** #5, #6, #4 из research-v5-features.md.
**Зона:** `core/src/engine/` (снимки ходов, чек-лист в шаге merge), `core/src/git.rs`, `core/src/model.rs` (точечно), `core/src/store.rs`, `app/src/main.rs` (точечно), `ui/js/screens/taskcard.js`, `ui/js/screens/chat.js` (только значок отката у реплик человека - перечитай перед правкой, его параллельно правит F12), `ui/css/need.css`, новый `ui/js/v4/i18n-task.js`.

1. **Откат на ход (#5).** Перед каждым запуском роли в worktree задачи - снимок дерева (включая незакоммиченное) в приватный ref `refs/nightshift/<task>/<n>` (не ветка, не засоряет историю, `git stash create` + `update-ref` или аналог). У каждой реплики человека и у каждого шага в ленте задачи - значок «Вернуть код сюда»: восстанавливает worktree к снимку (с подтверждением, текущее состояние тоже снимком - откат обратим). Только для задач в worktree, не для main. Снимки чистятся при удалении worktree.
2. **Чек-лист перед мержем (#6).** В карточке задачи список «До мержа»: человек добавляет/отмечает пункты; агент-ревьюер может добавить пункт (находка «вернулся с замечанием» → пункт). Merge-шаг не идёт, пока есть неотмеченные пункты: задача встаёт в «Ждёт тебя» с понятной причиной. Список передаётся исполнителю в промпт.
3. **«Забрать к себе» / «Отдать агенту» (#4).** В карточке задачи (не запущенной сейчас): «Забрать к себе» переключает основную папку проекта на ветку задачи (`ns/*`) безопасно: если в основной папке есть незакоммиченное - отказ с объяснением, ничего не теряется; worktree задачи при этом отцепляется/сохраняется по правилам git (ветка не может быть в двух worktree). «Отдать агенту» возвращает: основная папка - на прежнюю ветку, задача снова в своём worktree. Всё обратимо, без force.

**Критерии:** Rust-тесты: снимок и восстановление (незакоммиченный файл возвращается; ref не виден в `git branch`); merge не идёт при открытом пункте и идёт при закрытом; «Забрать» отказывает при грязной основной папке и переключает при чистой, «Отдать» возвращает исходную ветку. Selftest: значок отката у реплики, список «До мержа» в карточке, кнопки «Забрать/Отдать». Снимки f13-after. Общие проверки зелёные.
