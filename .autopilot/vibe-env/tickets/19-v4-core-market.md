## Что должно заработать

Спека: истории 266-273, «Решения по реализации v4» (Каталог, Дыра наборов), `research-catalogs.md` (источники, форматы, 12 правил безопасности), границы `core::net`, `core::market`, `core::kits` в «Границах v4».

`core::net` - `CurlFetch` (лимит размера, тайм-аут, ETag) и `FakeFetch`. `core::market` - источники: skills.sh (`/api/search`), маркетплейсы `marketplace.json` (anthropics/skills, anthropics/claude-plugins-official, claude-plugins-community), skillsmp (запасной); MCP - официальный реестр (`v0.1/servers`, `limit=10`, `metadata.nextCursor`), `api.mcp.github.com`, Smithery (по умолчанию выключен до сверки условий); моды - git-репозиторий / zip / папка. Поиск, карточка, план установки (что запишется, что исполняемо), применение через `kits` со снимком, установленное и обновления, удаление. Кэш индекса ≤ 24 ч, офлайн - кэш с датой. Свои источники. MCP пишется в конфиг среды форматом из research (Claude, Codex `config.toml`, Gemini `settings.json`, opencode); переменные - по именам, значения в связку ключей. `kits`: `SCRIPT_EXT` + `ts, tsx, jsx, mjs, cjs`; раздел «Моды» в экспорте/импорте (только Claude Code, `~/.claude/mods/<имя>`), мод выключен до галочки. Команды `market_*` в `app/src/market.rs` - настоящие вместо заглушек.

## Критерии приёмки

1. Тесты на записанных ответах источников (`fixtures/market/`, через `FakeFetch`): поиск и пагинация каждого источника, битый JSON - ошибка, не паника.
2. Установка скилла в Claude/Codex/Gemini кладёт файлы по путям из research; повтор - «установлено»; удаление и откат снимком возвращают как было.
3. Архив с `../`, абсолютным путём или симлинком наружу, больше 20 МБ или распаковкой > 100 МБ - отказ, ничего не записано.
4. Мод `clawd-run` (копия в фикстурах) при импорте помечен исполняемым (`register.tsx`) и выключен; включение - только явной галочкой.
5. MCP из реестра с переменной `API_KEY`: в конфиг уходит ссылка на имя, значение - в связку ключей; локальный сервер помечен «запускает код».
6. Один живой запрос к каждому включённому источнику (`#[ignore]`-тест, запускается вручную) - результат в отчёт.
