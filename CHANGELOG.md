# История изменений

## [1.0.2] - 2026-11-02

### Исправлено

- На Windows агенты, установленные через npm, запускаются через `.cmd`, без ошибки Win32 193 из-за соседнего Unix-скрипта. Поддерживаются явные пути без расширения и стандартный каталог npm.
- Символы `&`, `%` и кавычки в аргументах batch-агента передаются как данные и не становятся командами.
- Терминалы Windows правильно сообщают код завершения, сохраняют последние строки вывода и завершают дочерние процессы при закрытии.
- Чтение версии CLI не зависает при большом stderr или оставшемся открытым канале дочернего процесса.
- В Windows-консоли видны подсказки установки, а в заголовке остаётся имя агента.
- Палитра Windows/Linux показывает Ctrl вместо Cmd; у «Нового агента» убрана неверная подсказка Ctrl+T.

### Проверки

- В Windows CI добавлены native workflow, библиотечные тесты и JavaScript self-test.
- Сохранены отчёт и снимки автоматического прогона настоящего окна Windows 10. Облачные входы и Windows 11 этим прогоном не проверялись.
