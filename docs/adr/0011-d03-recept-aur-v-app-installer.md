# 0011. D03: рецепт AUR лежит в `app/installer/aur/`

## Контекст

Критерий G27 говорил, что PKGBUILD живёт в `packaging/aur/`. «Зона» таска 07 (установщики) при этом ограничивалась каталогом `app/installer/`, и пути противоречили друг другу.

## Решение

Рецепт AUR лежит в `app/installer/aur/PKGBUILD`. README и `install.sh` ссылаются на этот путь. Критерий G27 приведён в соответствие.

## Почему

- Путь `packaging/aur/` из критерия отвергнут: исполнитель тогда писал бы за пределами своей зоны, а границы зон нужны, чтобы таски не пересекались по файлам.
- Менять зону таска 07 под критерий отвергнуто: установочные файлы (`app/installer/`) уже собраны в одном месте, и разносить их по двум деревьям ради одного рецепта нет причин.

## Последствия

- Путь в документах для будущих мейнтейнеров AUR неочевиден: стандартного `packaging/` в репозитории нет.
- Пока проект не опубликован, в PKGBUILD стоят заглушки (`<OWNER>`, `<REPO>`, `sha256sums=SKIP`). Публикация потребует их заполнить.
- Любая ссылка на старый путь в документах должна быть исправлена; проверка пока только ручная.
