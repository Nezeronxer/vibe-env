# 0015. Каталоги ставят через наборы, скачанное считается недоверенным

## Контекст

Пользователь хочет «качать скиллы с популярных сайтов», ставить MCP и чужие моды (G40-G42). Моды и локальные MCP исполняют код на компьютере. В v1-v3 уже есть наборы (`core::kits`) со снимками, выключенным исполняемым и запретом секретов.

## Решение

`core::market` - это слой источников и скачивания. Запись на диск идёт только через `core::kits`, поэтому у каталога те же снимки, те же выключенные до галочки хуки, моды, `!cmd`, `tools:` и локальные MCP, тот же запрет секретов в файлах. Скачанное недоверенно: лимит 20 МБ на элемент, 100 МБ на распаковку, пути без `..`, абсолютных и симлинков наружу. Установка идёт в текущую среду (G22) и не затрагивает другие. Источники - встроенные плюс свои; недоступный источник показывает сохранённый список с датой. Frontmatter скилла читается по закрытому правилу: ключ, который не простой идентификатор, удерживает скилл до галочки.

## Почему

- Свой путь установки в каталоге отвергнут: пришлось бы дублировать снимки, откат и запрет секретов, и любая разница между двумя путями стала бы дырой.
- Установка сразу включённой с предупреждением отвергнута: мод и локальный MCP исполняются при первом запуске агента, и предупреждение никто не прочитает вовремя.
- Чёрный список ключей frontmatter отвергнут по итогу аудита (F4.2): скилл прятал `hooks` и `allowed-tools` за кавычками и экранированием (`"hoo\x6bs":`) и ставился без галочки. Закрыто правилом наоборот: подозрительно всё, что не простой идентификатор. Ту же ошибку раньше исправили для переменных наборов (F1.1, ADR 0006).
- `unzip` из системы отвергнут: он не проверяет каждый путь до распаковки. Распаковка идёт крейтом `zip` с проверкой.
- Идентификатор модели из каталога нельзя передавать в `-m` как есть (F4.1): теперь он проходит `is_model_id`.

## Последствия

- Большой поток источников нужно поддерживать: формат каждого API меняется независимо. Список источников пока записан в исследованиях, а не в коде.
- Часть источников выключена по умолчанию (SkillsMP, Smithery): они не ответили за 20 с, условия Smithery нужно сверить до включения.
- Каталог до 10 000 элементов требует локального индекса на диске со свежестью до 24 часов.
- Каталог ставит только в текущую среду; «поставить везде» одной кнопкой нет, это следствие замкнутого мира сред (ADR 0003).
- Позиция «исполняемое выключено» держится на списке расширений, который нужно дополнять. Кандидат D05 (`tsx`, `jsx`) уже показал, что список можно забыть пополнить: мод `clawd-run` не помечался исполняемым.
