# 0006. D04: из набора задаются только имена-секреты, плюс запрет классами

## Контекст

Спека (раздел про секреты наборов) не называла запрещённых имён. Ревью ветки 22.10 показало: чужой набор через `SHELL`, `ZDOTDIR`, `GIT_CONFIG_*`, `PYTHONPATH`, `*_BASE_URL` или прокси при каждом запуске агента запускает чужой код либо уводит ключ. Запрет классами закрыл это, но следующее ревью нашло переменные самих CLI (`CLAUDE_ENV_FILE`, `CLAUDE_CODE_SHELL_PREFIX`, `OPENCODE_CONFIG_CONTENT`, `CODE_ASSIST_ENDPOINT`), которые под классы не попадали.

## Решение

`kits::env_name_allowed` пропускает имя, только если оно оканчивается на `_KEY`, `_TOKEN`, `_SECRET` или `_PASSWORD` (без учёта регистра) и при этом не попадает под запрет классами: точные имена (`PATH`, `HOME`, `SHELL`, `ZDOTDIR`, `EDITOR` …), префиксы (`GIT_`, `SSH_`, `LD_`, `DYLD_`, `PYTHON`, `NODE_` …), суффиксы (`_HOME`, `_PATH`, `_PROXY`, `_BASE_URL` …). Значение - без CR, LF и NUL. Остальное - отказ `bad_name`.

## Почему

- Перечень точных имён отвергнут: опасность идёт семействами, любое пропущенное имя остаётся дырой.
- Один запрет классами отвергнут после аудита 22.10: у каждого CLI свои переменные, запускающие код или меняющие адрес, и их не перечислить заранее - следующий проверяющий всегда находил ещё одну.
- Полный запрет переменных набора отвергнут: набор должен передавать токены, ради этого секреты и вводятся.
- Разрешительный список совпадает с тем, как спека определяет секрет при экспорте набора (`*TOKEN*`, `*KEY*`, `*SECRET*`, `*PASSWORD*`), поэтому набор не теряет ничего, что сам считает секретом.

## Последствия

- Из набора не задать `TMPDIR`, `LANG`, `DEBUG`, `*_URL`, `JAVA_HOME`, `GOPATH`, `NODE_AUTH_TOKEN` и любые `*_HOME` / `*_PATH`. Исключение - только точечно и осознанно.
- Отказ видит получатель набора; нужную переменную вне секретов он задаёт сам, вне приложения.
- Тот же принцип (разрешено только безопасное) действует для настроек набора: без галочки ставятся лишь ключи из короткого безопасного списка среды, остальное ждёт подтверждения, как хук.
